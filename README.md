# Sales_Prediction_Using-Linear-Regression

## 📌 Project Overview
This project uses Linear Regression, a supervised machine learning algorithm, to predict sales based on advertising expenditure on TV, Radio, and Newspaper.

## 🎯 Objectives
- Analyze advertising expenditure and sales data.
- Perform Exploratory Data Analysis (EDA).
- Build a Linear Regression model.
- Predict sales using advertising data.
- Evaluate model performance.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset
The Advertising dataset contains the following features:

- **TV:** Advertising expenditure on TV.
- **Radio:** Advertising expenditure on Radio.
- **Newspaper:** Advertising expenditure on Newspaper.
- **Sales:** Target variable to be predicted.

## ⚙️ Project Workflow
1. Load the dataset.
2. Perform data exploration.
3. Conduct Exploratory Data Analysis (EDA).
4. Select input features and the target variable.
5. Split the dataset into training and testing sets.
6. Train the Linear Regression model.
7. Predict sales.
8. Evaluate the model using Mean Squared Error (MSE) and Mean Absolute Error (MAE)
